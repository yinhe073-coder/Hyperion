# 王者荣耀出装计算器（通用版）

用浏览器打开 `index.html`，右上角切换英雄。整个目录要放在一起，网页依赖 `calc.js` 和 `heroes/`。

## 结构

| 文件 | 作用 |
|---|---|
| `index.html` | 网页：选出装和铭文看结果、自动配铭文（卡攻速阈值）、全局优化、训练营测量清单 |
| `calc.js` | 通用计算：属性累加、阈值判定、铭文枚举、时间轴打分、全局优化，以及两个计算模型 |
| `heroes/houyi.js` | 后羿数据，用「普攻射手」模型（`adc`） |
| `heroes/milady.js` | 米莱狄数据，用「召唤物拆塔」模型（`summoner`），很多数字待实测 |
| `optimize.js` / `sensitivity.js` / `run.js` | 后羿的命令行优化、敏感性测试、阈值演示 |
| `early-late.js` | 后羿/孙悟空/米莱狄：4 级最强 + 发育最快（含小件顺序）、大后期卡阈值 |
| `三英雄_4级与大后期.md` | 上面的结果文档（以此为准） |
| `data/` | 王者营地装备库和大神出装原始数据（2026-11-06） |
| `houyi-camp.js` | 用王者营地当前装备数据重算后羿，对比大神出装（v3） |
| `milady-compare.js` | 米莱狄几套出装在不同机制假设下的对比和全局优化 |
| `milady-pvp.js` | 米莱狄前期打人优化（拆塔和打人加权，只看 3～12 分钟） |
| `milady-boots.js` | 固定疾步之靴，从装备池里自动挑剩下 5 件（选装优化，约 30 秒） |
| `后羿S45最终版.md` | 后羿最终出装铭文（以此为准） |
| `后羿S45出装铭文.md` | 后羿初版（已被最终版取代） |
| `米莱狄S45出装.md` | 米莱狄出装铭文（拆塔优先，兼顾移速） |

## 计算模型

- **adc（普攻射手）**：每秒伤害 = 有效攻速（超出上限无效）× 普攻伤害（暴击、护甲、穿透、末世、法球）。
- **summoner（召唤物拆塔）**：拆塔每秒伤害 = 机器人（吃法术攻击、冷却、二技能攻速、友方攻速光环）+ 英雄自身普攻。得分再乘以移速权重，用来兼顾逃跑。

## 加一个新英雄

复制 `heroes/houyi.js`（普攻英雄）或 `heroes/milady.js`（召唤物英雄），改掉 `id`、数值、`heroParams`、`defaultBuild` 和 `defaultIns`。然后在 `index.html` 里加一行 `<script src="heroes/新英雄.js"></script>`。
