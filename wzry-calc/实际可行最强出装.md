# 实际可行的最强出装：后羿 · 孙悟空 · 米莱狄 · 廉颇

> 2026-11-07。计算脚本：`practical.js`（`node practical.js 廉颇` 可单独跑一个英雄）。

## 怎么选出来的

- **候选出装全部来自王者营地大神榜**（2026-11-06 更新），再加少量能多卡阈值的变体。不推纸面最优、实际没人出的装备。
- **第 1 件固定是鞋子**；打野是**打野刀 → 鞋子**。
- **铭文整局一套**。每套出装都枚举所有铭文组合，挑「4 级强度 × 后期强度」综合最高的那一套。
- 装备数值和合成配方来自营地装备库，技能参数来自官网。英雄基础属性、对面护甲这类数是估计值，所以只看方案之间的相对排名。
- 每个英雄给出「综合最强」；如果「卡阈值最多」的是另一套，也一并列出。

> ⚠ **更正：** 之前的计算里，贤者天书的被动放大了 100 倍（「每 100 法攻 +0.5%」写成了每 1 法攻 +0.5%），带贤者天书的米莱狄后期结论被高估了。本文已修正。修正后贤者天书路线仍然最好，但只比大神的梦魇路线高 5～10%，不再是之前的一大截。

## 一、后羿（发育路）

### ★ 综合最强：急速战靴 → 影刃 → 无尽战刃 → 仁者破晓 → 末世 → 强者破军
- **铭文：** 4 无双 6 祸源 + 6 狩猎 4 隐匿 + 10 鹰眼
- **卡住的阈值（2/3）：** 攻速 153.7%（上限 153.2%）✔，无尽暴击效果满额 ✔，暴击 67%（没到 100%）
- **4 级（约 1500 金）：** 急速战靴 + 铁剑 + 匕首；物攻 247，攻速 51%
- **小件顺序：**
  1. 神速之靴 → 匕首 → **急速战靴**
  2. 铁剑 → 匕首 → 搏击拳套 → 雷鸣刃 → 附魔之羽 → 狂暴双刃 → **影刃**
  3. 铁剑 → 风暴巨剑 → 搏击拳套 → 铁剑 → 雷鸣刃 → **无尽战刃**
  4. 搏击拳套 → 匕首 → 穿云弓 → 铁剑 → 匕首 → 速击之枪 → **仁者破晓**
  5. **末世**（格子紧，直接买二级件：血魂刃 + 精钢锻刀）
  6. 铁剑 → 风暴巨剑 → **强者破军**
- 需要保命时，第 6 件换名刀·司命或贤者的庇护。综合得分会降到大约 90，但更不容易被秒。

### ◆ 卡阈值最多（3/3）：第 5、6 件换成逐日之弓 + 幽影袖箭
- **铭文：** 6 无双 4 祸源 + 10 隐匿 + 10 鹰眼
- 攻速 171%、**暴击 100.6%**、无尽满额，三个都卡满；综合得分约 92。

## 二、孙悟空（打野，惩戒）

### ★ 综合最强：追击刀锋 → 急速战靴 → 无尽战刃 → 影刃 → 宗师之力 → 强者破军（追击刀锋后期升级为贪婪之噬）
- **铭文：** 7 无双 3 红月 + 10 狩猎 + 10 鹰眼
- **卡住的阈值（1/4）：** 无尽满额 ✔（暴击 86%）；攻速 117%，停在 116 档
- **4 级（约 1400 金）：** 追击刀锋 + 急速战靴；物攻 274，攻速 38%，暴击 26%
- **小件顺序：**
  1. 狩猎宽刃 → **追击刀锋**
  2. 神速之靴 → 匕首 → **急速战靴**
  3. 铁剑 → 风暴巨剑 → 搏击拳套 → 铁剑 → 雷鸣刃 → **无尽战刃**
  4. 搏击拳套 → 匕首 → 铁剑 → 雷鸣刃 → 附魔之羽 → 狂暴双刃 → **影刃**
  5. **宗师之力**（雷鸣刃 + 精钢锻刀）
  6. **贪婪之噬**（追击刀锋 + 陨星，打野刀升级）
  7. 铁剑 → 风暴巨剑 → **强者破军**

### ◆ 卡阈值最多（2/4）：第 5、6 件换成末世 + 制裁之刃
- **铭文：** 6 无双 4 红月 + 10 狩猎 + 10 鹰眼
- 攻速**正好 152.0%**（最高档）✔，无尽满额 ✔；综合得分约 93。

## 三、米莱狄 · 打野（惩戒）

### ★ 综合最强 = 卡阈值：游击弯刀 → 冷静之靴 → 贤者天书 → 博学者之怒 → 符文大剑 → 日暮之流 → 凝冰之息
- **铭文：** 10 梦魇 + 10 狩猎 + 10 心眼
- **4 级（约 1400 金）：** 游击弯刀 + 冷静之靴；法攻 130，法穿 88，冷却 15%
- **小件顺序：**
  1. 狩猎宽刃 → **游击弯刀**
  2. 神速之靴 → 元流结晶 → **冷静之靴**
  3. 咒术典籍 → 大棒 → 咒术典籍 → 元流结晶 → 圣者法典 → **贤者天书**
  4. 咒术典籍 → 大棒 → **博学者之怒**
  5. 元流结晶 → 咒术典籍 → 圣者法典 → **符文大剑**（游击弯刀升级）
  6. **日暮之流**、**凝冰之息**（格子紧，按二级件买）
- **后期换鞋：** 成型后冷却会到 57.5%，溢出 17.5%。**把冷静之靴免费换成秘法之靴**，冷却 42.5% 照样卡满，多出来的冷却变成了法穿。

## 四、米莱狄 · 对抗路（传送）

### ★ 综合最强 = 卡阈值：冷静之靴 → 贤者天书 → 博学者之怒 → 日暮之流 → 回响之杖 → 虚无法杖
- **铭文：** 10 梦魇 + 10 狩猎 + 10 心眼
- **卡阈值：** 冷却**正好 40.0%** ✔（冷静之靴 15 + 日暮之流 10 + 贤者天书 10 + 虚无法杖 5）
- **4 级（约 1200 金）：** 冷静之靴 + 咒术典籍
- **小件顺序：**
  1. 神速之靴 → 元流结晶 → **冷静之靴**
  2. 咒术典籍 → 大棒 → 咒术典籍 → 元流结晶 → 圣者法典 → **贤者天书**
  3. 咒术典籍 → 大棒 → **博学者之怒**
  4. 元流结晶 → 咒术典籍 → 圣者法典 → 咒术典籍 → 红玛瑙 → 云灵木 → **日暮之流**
  5. **回响之杖**、**虚无法杖**（格子紧，按二级件买）
- **对比：** 大神常用的「梦魇之牙 → 痛苦面具 → 日暮之流 → 凝冰之息 / 贤者天书 → 博学者之怒」综合得分 94～95，差距不大，按手感选。

## 五、廉颇（对抗路）

### ★ 综合最强 = 卡阈值：冷静之靴 → 怒龙剑盾 → 红莲斗篷 → 霸者重装 → 血魔之怒 → 极寒风暴
- **铭文：** 10 宿命 + 10 调和 + 9 虚空 1 鹰眼（满生命流）
- **卡阈值：** 冷却 40.4% ✔
- **4 级（约 1300 金）：** 冷静之靴 + 布甲 + 红玛瑙；生命约 5500，护甲 318
- **15 级：** 生命约 **1.44 万**，护甲 1193，法抗 399
- **小件顺序：**
  1. 神速之靴 → 元流结晶 → **冷静之靴**
  2. 布甲 → 红玛瑙 → 守护者之铠 → 抗魔披风 → 红玛瑙 → 神隐斗篷 → **怒龙剑盾**
  3. 红玛瑙 → 力量腰带 → 布甲 → 红玛瑙 → 守护者之铠 → **红莲斗篷**
  4. 红玛瑙 → 力量腰带 → **霸者重装**
  5. 红玛瑙 → 力量腰带 → 铁剑 → 风暴巨剑 → **血魔之怒**
  6. **极寒风暴**（格子紧，直接买二级件：急速铠甲 + 雪山圆盾）
- **为什么堆生命：** 廉颇二技能和大招带 4%～6% 最大生命的加成，红莲斗篷、怒龙剑盾、血魔之怒的被动也按最大生命算。所以生命越高，既越肉、伤害也越高。
- **其他大神出装（综合得分）：** 血魔极寒 + 不死鸟之眼（营地胜率 66%）97.6；血魔 + 贤者的庇护 95.4；怒龙 + 冰霜冲击 + 魔女斗篷 + 不祥征兆 96.6，但冷却卡不满。
- 对面法师多就把极寒风暴换成魔女斗篷，射手多就换成不祥征兆，得分只差几个点。
